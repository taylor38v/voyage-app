AUTO-REMPLISSAGE DES INFOS PRATIQUES EN FONCTION DE LA DESTINATION

Dans le bloc "Infos pratiques" (section "infos" du nouveau TripEditor avec les 9 blocs), ajouter un remplissage automatique.

COMPORTEMENT :

1. Quand l'admin ouvre le Dialog "Infos pratiques", en haut du formulaire afficher :
   - Un texte : "Destination actuelle : [trip.destination]"
   - Un bouton "🪄 Remplir automatiquement" (style gradient violet, comme le bouton IA existant)
   - Ce bouton est DISABLED si trip.destination est vide/null (avec un message "Définissez d'abord une destination dans le bloc 'Le Voyage'")

2. Au clic sur "Remplir automatiquement" :
   - Appel à une NOUVELLE route : POST /api/admin/trips/:id/auto-fill-info
   - Le body contient : { destination: trip.destination }
   - Le serveur utilise un MAPPING STATIQUE (pas d'API externe) pour les pays les plus courants
   - Loading state avec spinner pendant le traitement

4. La logique serveur :
   - Extraire le pays de la destination (ex: "Bangkok, Thaïlande" → chercher "thaïlande" dans les clés)
   - Normaliser : toLowerCase(), trim(), enlever les accents pour la recherche
   - Si trouvé : mettre à jour trip.travelInfo avec les données et renvoyer le trip mis à jour
   - Si pas trouvé : renvoyer 404 avec { message: "Pays non reconnu. Remplissez les infos manuellement." }

5. CÔTÉ CLIENT dans le Dialog "Infos pratiques" :
   - Au succès : les champs se pré-remplissent avec les données reçues
   - L'admin peut MODIFIER chaque champ avant de sauvegarder
   - Toast : "Infos pratiques pré-remplies pour la Thaïlande ! Vérifiez et ajustez si nécessaire."
   - Si erreur 404 : toast warning "Pays non reconnu, remplissez manuellement"

6. Pour la recherche du pays, utiliser une fonction robuste qui :
   - Cherche dans trip.destination (ex: "Bali, Indonésie" ou "Tokyo" ou "Brésil")
   - Compare avec les clés du mapping en normalisant (sans accents, lowercase)
   - Peut aussi matcher des noms de villes connues aux pays (bangkok → thaïlande, tokyo → japon, rome → italie, bali → indonésie, etc.)
