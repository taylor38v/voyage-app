=== 2. COMPORTEMENT DES BOUTONS CTA ===

Chaque bouton CTA doit :
- Si l'utilisateur N'EST PAS connecté : rediriger vers /api/login (authentification)
- Si l'utilisateur EST connecté : appeler POST /api/stripe/checkout avec le priceId correspondant au plan ET à l'intervalle (mensuel/annuel), puis rediriger vers l'URL Stripe Checkout retournée

Pour cela, stocker les Price IDs en dur dans le composant pricing via des constantes :
```ts
const PRICES = {
  solo: {
    monthly: { price: 19, priceId: import.meta.env.VITE_STRIPE_PRICE_SOLO_MONTHLY || "" },
    yearly: { price: 190, priceId: import.meta.env.VITE_STRIPE_PRICE_SOLO_YEARLY || "" },
  },
  pro: {
    monthly: { price: 49, priceId: import.meta.env.VITE_STRIPE_PRICE_PRO_MONTHLY || "" },
    yearly: { price: 490, priceId: import.meta.env.VITE_STRIPE_PRICE_PRO_YEARLY || "" },
  },
  agency: {
    monthly: { price: 99, priceId: import.meta.env.VITE_STRIPE_PRICE_AGENCY_MONTHLY || "" },
    yearly: { price: 990, priceId: import.meta.env.VITE_STRIPE_PRICE_AGENCY_YEARLY || "" },
  },
};
```
